# Demo assets

`loadout.tape` is a [VHS](https://github.com/charmbracelet/vhs) script. It
renders `loadout.gif` for the README.

```bash
vhs docs/demo/loadout.tape
```

Regenerate it whenever the interface changes. Keeping the demo in version
control means it can be reviewed and rebuilt, rather than being a stale
screenshot nobody can reproduce.
